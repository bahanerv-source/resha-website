# ريشة — الموقع

موقع عربي (RTL) لعرض منتجات ريشة وعروضها، والطلب عبر واتساب. لا سلة ولا دفع ولا حسابات.

Homepage → Category → Product → Personalisation → WhatsApp.

## التشغيل

```bash
npm install
npm run dev      # معاينة على http://localhost:3000 — تُحدَّث الصفحة وحدها بعد كل تعديل
npm run live     # مثل dev، ويجلب أيضاً أي تعديلات جديدة من GitHub كل 15 ثانية (اتركه يعمل وافتح الصفحة فقط)
```

على الماك: انقر مرتين على الملف `Preview.command` في مجلد الموقع — يجلب آخر التعديلات ويفتح المعاينة ويحدّثها وحده.

```bash
npm run build    # ينتج مجلد dist/ الجاهز للنشر
```

### النشر على Vercel

ارفع المجلد إلى GitHub ثم استورده في Vercel. الإعدادات موجودة في `vercel.json`
(أمر البناء `npm run build`، مجلد النشر `dist`). لا حاجة لأي خادم أو قاعدة بيانات.

## قبل الإطلاق — غيّر هذه القيم

| ماذا | أين |
| --- | --- |
| رقم واتساب (رقم واحد لكل الأزرار) | `src/config/site.ts` → `whatsappNumber` (مثال: `962791234567`) |
| روابط إنستغرام وفيسبوك | `src/config/site.ts` → `social` |
| عنوان الموقع الحقيقي (للروابط و SEO) | `src/config/site.ts` → `url` |
| ساعات الرد | `src/config/site.ts` → `whatsappHours` |
| الأسعار والأسماء والصور | `src/data/products.ts` (المحتوى الحالي نموذجي) |
| تواريخ انتهاء العروض | `src/data/offers.ts` و `src/data/campaigns.ts` → `endsAt` (التواريخ الحالية نموذجية) |

## التعديل اليومي (بدون إعادة تصميم)

كل المحتوى في مجلد `src/data/` — المكوّنات تقرأ منه فقط:

- **إضافة منتج:** انسخ منتجاً في `src/data/products.ts` وغيّر `slug` والاسم والسعر والصور.
- **حذف منتج:** احذف عنصره من القائمة (وأزل الـ slug من `home.ts` إن كان مستخدماً هناك).
- **تغيير سعر:** `price`. ضع `compareAt` فقط عند وجود سعر سابق حقيقي.
- **أسعار الكميات للمدارس:** `tiers: [{ min: 1, price: 12 }, { min: 10, price: 10 }]`.
- **ضم منتج لعرض:** `offerId: 'buy10get10'` — صفحة المنتج تحسب القطع المجانية تلقائياً.
- **تغيير القسم:** `category` (القسم الأساسي) و `alsoIn` (أقسام إضافية).
- **حقول التخصيص:** `fields` — اختر فقط ما يحتاجه المنتج: `occasion`, `schoolName`, `recipient`, `from`, `text`, `year`, `names`, `logo`, `photo`.
- **عرض جديد:** أضفه في `src/data/offers.ts` (أنواع: `bxgy` اشترِ X واحصل على Y، `percent` خصم، `bundle` باقات).
- **المناسبة الحالية (الهيرو):** جهّز الحملة في `src/data/campaigns.ts` ثم غيّر `currentCampaign` في `src/config/site.ts`.
- **ترتيب الصفحة الرئيسية:** `src/data/home.ts` — رتّب الأقسام أو احذفها أو كرّرها.
- **البانرات:** `banners` (البانرات الكبيرة) و `strips` (الشرائط بين صفوف المنتجات) في `src/data/campaigns.ts`.

### الصور

ضع الصور الحقيقية في `public/images/products/` واكتب مسارها في `images`
(مثال: `'/images/products/plaque-gold-1.jpg'`). الصورة الأولى هي صورة البطاقة.
عند البناء تُنشأ تلقائياً نسخ WebP بمقاسات 480/960/1600 لكل صورة JPG/PNG.

- صور المنتجات مربّعة 1:1 (البطاقات وصفحة المنتج)، على خلفية بيضاء.
- بانر الرئيسية: تصميم جاهز بنسبة 3:1 (مثل 2000×667) يحمل العنوان والزر داخل الصورة — ضعه في `public/images/banners/` واكتب مساره في `artwork` للحملة (`src/data/campaigns.ts`) مع `textSide` (الجهة التي فيها النص، ليُقصّ الجوال نحوها). بانرات إضافية للشريط المتحرك في `heroSlides` وترتيبها في `src/data/home.ts`.
- صور المنتجات المؤقتة (خلفية بيضاء) في `public/images/products-ph/`، وصور الحملات والبانرات في `public/images/placeholders/` — كلها رسومات مؤقتة، استبدلها بصور حقيقية قبل الإطلاق.
- للحصول على مظهر متناسق: صوّر المنتجات على خلفية بيضاء أو فاتحة جداً، واترك الألوان (العنابي، الكريمي، الذهبي) لصور الحملات.

## البنية التقنية

- React 19 + TypeScript، تُرسم كل الصفحات مسبقاً إلى HTML ثابت (سريع، ممتاز لمحركات البحث).
- الأجزاء التفاعلية فقط ("islands") تُحمَّل بجافاسكربت: القائمة والبحث، معرض الصور، نموذج التخصيص وواتساب، تصفية الأقسام، العدّاد.
- الشكل البصري الحالي (صفحات بيضاء، نصوص وأزرار سوداء، عناوين بخط Noto Naskh Arabic ونصوص بخط Noto Sans Arabic، صور بزوايا ناعمة، الأحمر لأسعار العروض فقط) في `src/styles/theme.css` — هو المرجع للشكل ويُحمَّل أخيراً، ويعيد تعريف ألوان `tokens.css`. الملفات `tokens.css` و `ds.css` و `site.css` أساس للمكوّنات والتخطيط فقط.
- الخطوط مستضافة مع الموقع نفسه (حزمتا `@fontsource-variable/noto-sans-arabic` و `noto-naskh-arabic`) — لا تعتمد على Google Fonts.
- SEO: عنوان ووصف لكل صفحة، روابط canonical، Open Graph، بيانات منظّمة (Store، Product، BreadcrumbList)، `sitemap.xml` و `robots.txt`.

```
src/
  config/site.ts        إعدادات عامة (واتساب، روابط، الحملة الحالية)
  data/                 الأقسام، المنتجات، العروض، الحملات والبانرات، ترتيب الرئيسية
  components/           مكوّنات العرض (بطاقات، بانرات، هيدر، فوتر)
  islands/              المكوّنات التفاعلية
  pages/                الصفحات
  render/               توليد HTML لكل الصفحات
  styles/               tokens + نظام التصميم + تخطيط الموقع
scripts/build.mjs       البناء
public/                 الصور والشعار
```
